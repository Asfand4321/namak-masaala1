How it works
1. Aap apne dost ko invite karte hain aur apna referral code share karte hain.
2. Dost signup karta hai aur koi bhi weekly ya monthly plan choose karta hai.
3. Checkout par wo aapka referral code use karta hai.
4. System plan ke type ko dekhta hai (Weekly 1, Weekly 2, Monthly 1, Monthly 2)
5. Usi ke hisaab se Rs 200 / 400 / 800 / 1600 discount apply hota hai.

Optional: Backend me aapko bhi same amount wallet credit ke taur par mil sakta hai (ye part admin side se define hoga).
